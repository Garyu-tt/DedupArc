## 1.1.0 — 2026-11-08

- Экспериментальный профиль CLI `create --extreme` для потерь-ноль сжатия похожих бинарных версий.
- Формат v3: дельта-блоки с SHA-256 ссылки на более ранний обычный блок; цепочки дельт запрещены.
- Выбор обычного блока или дельты по фактическому полному размеру; ограниченный 64-МиБ словарь.
- Проверка SHA-256 при восстановлении, тесты повреждённой ссылки и полной распаковки.
- Поведение fast/balanced/maximum и совместимость записи v2 сохранены.
- Воспроизводимый набор тестов для versioned/random/text плюс сравнение с tar.xz/zstd.

# История изменений

## 1.0.0 — 2026-08-09

Первый публичный стабильный выпуск DedupArc.

### Архивация

- один проход дерева входных данных вместо предварительного полного пересканирования;
- ускоренное перечисление каталогов Windows через `FindFirstFile/FindNextFile`;
- параллельный read-ahead для мелких файлов с ограниченным использованием памяти;
- порог упаковки мелких файлов увеличен до 256 КиБ;
- стандартный размер общего блока мелких файлов увеличен до 16 МиБ;
- обычный профиль использует более сильное сжатие для данных, которые имеет смысл сжимать;
- частота обновления прогресса ограничена, чтобы UI не становился частью горячего пути;
- отмена доступна уже во время сканирования большого дерева.

### Windows

- ассоциация `.darc` и собственная иконка;
- команды Проводника для создания, распаковки и проверки;
- рабочая сессия позволяет запускать программы непосредственно из архива;
- одна установленная копия приложения без каталогов версий;
- атомарное обновление с SHA-256, Ed25519, self-test и rollback.

### Совместимость

- создание формата `.darc` v2;
- чтение формата v1 сохранено.
