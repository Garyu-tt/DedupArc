# DedupArc 1.0.0

Первый публичный стабильный выпуск.

Главное в 1.0 — быстрый путь для каталогов с большим количеством мелких файлов: один проход дерева, ускоренное перечисление NTFS-каталогов, параллельный read-ahead и общие 16-МиБ блоки для небольших файлов.

Также в выпуск входят:

- собственный формат `.darc` с дедупликацией;
- режимы сжатия Fast / Balanced / Maximum;
- запуск программ непосредственно из архива через рабочую сессию;
- ассоциация `.darc` и команды Проводника;
- установщик, обновлятор и автоматический rollback при неудачном self-test;
- чтение архивов старого формата v1.

Перед публикацией сборка проходит `go test ./...`, `go vet ./...` и Windows build workflow.
