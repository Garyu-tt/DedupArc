# DedupArc 1.1.0 — Extreme R01

- **Новый экспериментальный режим:** `deduparc-core create --extreme out.darc data/`.
- Сохранение уникальных похожих блоков как точных XOR-дельт с SHA-256
  ссылкой на ранее записанный блок, при доказанном выигрыше по размеру.
- Формат v3 для Extreme. Обычные режимы продолжают записывать v2,
  а v1/v2/v3 читаются новой версией.
- Новые тесты дельта-повреждений и полный SHA-256 roundtrip,
  воспроизводимый бенчмарк и сравнение с XZ/Zstd.

На синтетических 10 бинарных версиях 41,94 МБ → 4,25 МБ
(9,86x относительно исходника). Сторонние XZ/Zstd на этом наборе
немного меньше; **это не универсальный рекорд сжатия**.

Extreme пока доступен только через CLI; Explorer и остальные
режимы не меняют своё поведение.

**Важно:** приложение 1.0 не обязано читать новые v3-архивы.
