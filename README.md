<h1 align="center">DedupArc</h1>

<p align="center">
  Быстрый архиватор для Windows с дедупликацией, упаковкой мелких файлов и собственным форматом <code>.darc</code>.
</p>

DedupArc выглядит и ведёт себя как обычный архиватор: `.darc` открывается двойным щелчком, содержимое просматривается через привычный файловый интерфейс, а создание, распаковка и проверка доступны из Проводника.

Главная особенность формата находится внутри. Одинаковые участки данных не записываются повторно, а большие деревья мелких файлов собираются в крупные блоки вместо тысяч отдельных сжатых потоков.

## Возможности

- самодостаточный формат `.darc`;
- content-defined дедупликация похожих и одинаковых данных;
- отдельная оптимизация деревьев с десятками тысяч мелких файлов;
- три режима сжатия: **быстро**, **обычно** и **максимум**;
- автоматический пропуск бессмысленного повторного сжатия уже сжатых форматов;
- открытие и запуск программ прямо из архива через рабочую сессию;
- проверка целостности архива перед заменой существующего файла;
- ассоциация `.darc`, собственная иконка и команды контекстного меню;
- установщик и атомарный обновлятор с автоматическим откатом;
- CLI для скриптов и автоматизации.

## Почему много мелких файлов больше не так больно

Обычный SSD очень быстро читает большие последовательные потоки, но десятки тысяч отдельных файлов всё равно требуют большого количества операций с каталогами, метаданными, открытием и закрытием файлов.

В DedupArc 1.0 этот путь оптимизирован отдельно:

- дерево входных данных сканируется **один раз**, а не два;
- на Windows используется прямое перечисление `FindFirstFile/FindNextFile`, без дополнительного запроса метаданных для каждого элемента;
- мелкие файлы читаются с параллельным read-ahead, чтобы SSD не простаивал между короткими операциями;
- файлы до 256 КиБ по умолчанию собираются в общие блоки примерно по 16 МиБ;
- одинаковые мелкие файлы внутри набора физически хранятся один раз;
- обновление окна прогресса ограничено по частоте и не вызывается десятки тысяч раз в секунду.

Прямое чтение MFT или raw-доступ к файловой системе намеренно не используются: DedupArc не требует повышенных прав для обычной архивации.

## Сжатие

Для обычной работы используется режим **Обычно**. Он сильнее сжимает обычные данные, а небольшие файлы сначала группирует по типу содержимого и сжимает совместно.

CLI позволяет выбрать режим явно:

```text
deduparc-core create --fast archive.darc folder
deduparc-core create --balanced archive.darc folder
deduparc-core create --maximum archive.darc folder
```

`--balanced` используется по умолчанию.

Для ZIP, JPEG, PNG, MP4, JAR и других форматов, которые обычно уже содержат сжатые данные, DedupArc старается не тратить процессор на бессмысленную повторную работу. Для остальных данных сжатие проверяется по фактическому результату: если сохранённый блок не становится меньше, он записывается как есть.

## Запуск прямо из архива

При открытии `.darc` DedupArc создаёт рабочую сессию как обычное дерево файлов. Благодаря этому программа, запущенная из архива, видит соседние DLL, конфиги, ресурсы и подкаталоги по привычным относительным путям.

После закрытия файлового менеджера DedupArc ждёт завершения процессов, запущенных из рабочей сессии. Если содержимое было изменено, архив пересобирается во временный файл, проверяется и только после этого атомарно заменяет прежнюю версию.

## Установка

Скачайте `DedupArc-1.0.0-Setup.exe` из Releases и запустите его.

Установщик:

- ставит одну копию DedupArc в `%LOCALAPPDATA%\Programs\DedupArc`;
- при необходимости предлагает установить официальный 7-Zip File Manager;
- регистрирует расширение `.darc` и его иконку;
- добавляет команды создания, распаковки и проверки в Проводник;
- создаёт ярлык в меню «Пуск»;
- выполняет самопроверку до завершения установки.

Повторная установка и обновление заменяют текущую копию приложения. Каталоги разных версий рядом не создаются.

## Обновления

`DedupArcUpdater.exe` проверяет GitHub Releases не чаще одного раза в сутки.

Обновление полностью скачивается во временный каталог, проверяется по Ed25519-подписи и SHA-256, ждёт закрытия приложения, переключает установленный каталог целиком и запускает self-test. Если новая версия не проходит проверку, предыдущая автоматически возвращается на место.

## CLI

```text
deduparc-core create archive.darc folder
deduparc-core list archive.darc
deduparc-core extract archive.darc output
deduparc-core verify archive.darc
deduparc-core info archive.darc
```

Для обычной работы CLI не нужен.

## Производительность

В [`docs/BENCHMARK.md`](docs/BENCHMARK.md) находится небольшой воспроизводимый тест, ориентированный именно на большое количество небольших файлов. Он не является универсальным сравнением с другими архиваторами.

Реальный результат зависит от структуры данных, файлового кэша, антивируса, накопителя и выбранного режима сжатия.

## Сборка

Нужны Windows x64, PowerShell и Go 1.23+.

```powershell
.\scripts\build-windows.ps1
```

Скрипт запускает тесты и `go vet`, собирает приложение, обновлятор и установщик, а затем формирует пакет обновления.

## Формат

DedupArc 1.0 создаёт `.darc` формата версии 2 и продолжает читать архивы версии 1.

Техническое описание находится в [`FORMAT.md`](FORMAT.md).

## Интерфейс 7-Zip

DedupArc использует 7-Zip File Manager как файловый интерфейс. Нужные компоненты копируются в локальный runtime DedupArc во время установки.

Лицензионная информация сторонних компонентов находится в [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).
