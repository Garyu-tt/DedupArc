# Разработка

Требования к изменениям простые:

- `go test ./...` и `go vet ./...` должны проходить перед коммитом;
- пользовательский интерфейс не должен показывать внутреннее устройство формата без необходимости;
- запись архива и обновления приложения должны оставаться атомарными;
- комментарии пишутся по-русски и только там, где код действительно требует пояснения;
- приватный release-ключ никогда не добавляется в репозиторий.

Для публикации обновлений положите base64-ключ Ed25519 в GitHub Actions secret `DEDUPARC_RELEASE_KEY`.
