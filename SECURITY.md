# Безопасность

Если проблема позволяет повредить архив, подменить обновление, выйти за каталог распаковки или выполнить неожиданный код, не публикуйте подробный exploit в открытом issue до исправления.

Для первоначального сообщения используйте приватный канал GitHub Security Advisories репозитория DedupArc. В сообщении желательно указать версию, минимальные шаги воспроизведения и ожидаемое влияние.

Публичный issue подходит для обычных ошибок интерфейса, совместимости и производительности.
