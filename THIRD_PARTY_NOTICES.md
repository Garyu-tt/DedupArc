# Сторонние компоненты

## 7-Zip

DedupArc использует 7-Zip File Manager в качестве файлового интерфейса.

Установщик DedupArc при необходимости загружает официальный установщик 7-Zip 26.02, проверяет его SHA-256 и запускает штатную тихую установку. После этого нужные файлы 7-Zip копируются из установленного каталога в локальный runtime DedupArc.

7-Zip создан Игорем Павловым. Основная часть 7-Zip распространяется по GNU LGPL; отдельные части имеют BSD 3-clause и unRAR license restrictions. Актуальные условия и исходный код доступны на официальном сайте 7-Zip.

Официальный сайт: `https://www.7-zip.org/`

DedupArc не заявляет авторство над кодом или интерфейсом 7-Zip.
